# NorthStar

**Your capability. Your path. Your evidence.**

Mobile-first cybersecurity capability platform.

## UI phase 0.1.0
- Home
- Learn / curriculum
- Labs
- AI companion shell
- Progress
- Liquid glass bottom navigation
- Local lesson completion state
- No external API dependency

GitHub Pages is the deployment target. The project intentionally starts as a static, dependency-free application so UI behavior can be validated before introducing a backend.

## Validation
The application is designed to work from the repository root and uses relative asset paths for GitHub Pages project hosting.
