# Curriculum 2.0 + Learner Model

NorthStar keeps the existing 16-pathway curriculum as the content source. Version 2.0 adds a measurable capability contract and learner state rather than replacing the content.

## Lesson quality contract
Lessons should progressively cover objective, prerequisite, concepts, first-principles explanation, worked example, case analysis, guided practice, independent practice, assessment, takeaways and authoritative references where appropriate.

## Capability progression
Foundation → Core → Applied → Advanced → Integration.

## Mastery
Completion records exposure. Knowledge-check performance creates concept evidence. Practice and lab evidence are the next layers. Mastery is stored locally and can later drive adaptive remediation.

## Adaptive loop
Diagnose → teach → practice → assess → record evidence → remediate → re-assess → advance.

## Implementation roadmap
1. Map every lesson to prerequisite concepts.
2. Generate a knowledge graph from those relationships.
3. Add remediation links between weak concepts and foundation lessons.
4. Add practice and lab evidence to mastery.
5. Build curriculum-aware RAG over authoritative lesson content.
6. Add adaptive lesson recommendations.
